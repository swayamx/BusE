# 🚍 School Safety Transport System – Bus e-Project

A smart, reliable, and safety-first transport management system built for schools. This project blends traditional safety values with modern technology to ensure students travel securely from home to school and back.

🔎 Overview

The School Safety Transport System is designed to improve transparency, punctuality, and oversight in school transportation. Parents, drivers, and school administrators stay connected through real-time updates and automated alerts—making every ride safer and more accountable.

⭐ Key Features
🛰️ Real-Time Bus Tracking

Live GPS-based bus tracking that shows location updates to parents and school admin.

🧒 Student Check-In / Check-Out

RFID/QR scan for student boarding and deboarding to avoid manual errors.

🔔 Instant Notifications

Parents receive alerts for bus arrival, delays, route changes, and student entry/exit.

👨‍✈️ Driver Dashboard

Easy interface for drivers to view routes and start/stop trips.

🏫 Admin Control Panel

Monitor buses, routes, students, drivers, and trip history from one place.

🚨 Emergency SOS

One-tap alert for emergencies, notifying parents and school authorities instantly.

💻 Tech Stack

🎨 Frontend: HTML, CSS, JavaScript

🛠️ Backend: PHP

🗄️ Database: MySQL

📡 Tracking: GPS module / API integration

🎫 Hardware (Optional): RFID / QR Scanner

🔁 System Workflow

🏫 Admin adds students, buses, routes, and drivers.

🚌 Driver starts the trip and begins sharing live location.

🎫 Students scan RFID/QR on entering or exiting the bus.

📲 Parents receive real-time updates and notifications.

📊 Admin dashboard displays complete route history and attendance logs.

🎯 Why This Project Matters

This system respects the long-standing importance of safety in school transport while embracing future-ready features. It builds trust between schools and families, ensuring every journey is secure and transparent.
